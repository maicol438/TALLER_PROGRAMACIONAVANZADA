2. DESCRIPCIÓN
------------------------------------------------------------------------
  API REST que administra un catálogo de vehículos. Los datos se guardan en
  MongoDB y las lecturas individuales se cachean en Redis aplicando una
  política de expiración (TTL) según el nombre y la descripción del vehículo.

  Tecnologías: Python 3.12, Flask 3.1, MongoDB 8.0, Redis 7.4, Docker Compose.

------------------------------------------------------------------------
3. ENDPOINTS
------------------------------------------------------------------------
  GET    /salud              -> Estado del servicio
  GET    /vehiculos          -> Lista todos los vehículos
  POST   /vehiculos          -> Crea un vehículo (201)
  GET    /vehiculos/<id>     -> Consulta un vehículo (MongoDB o Redis)
  PUT    /vehiculos/<id>     -> Actualiza parcialmente e invalida caché
  DELETE /vehiculos/<id>     -> Elimina e invalida caché (204)

------------------------------------------------------------------------
4. POLÍTICA DE CACHÉ
------------------------------------------------------------------------
  - Descripción > 20 caracteres  -> NO se cachea.
  - Nombre <= 5 caracteres       -> TTL 15 s.
  - Nombre <= 10 caracteres      -> TTL 20 s.
  - Nombre > 10 caracteres       -> TTL 40 s.

------------------------------------------------------------------------
5. CÓMO EJECUTAR (Windows / Docker Desktop)
------------------------------------------------------------------------
