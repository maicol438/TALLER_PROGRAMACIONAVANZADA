========================================================================
ENTREGA — API REST DE VEHÍCULOS (Flask + MongoDB + Redis)
========================================================================

1. CÓMO FUNCIONA EL CÓDIGO
------------------------------------------------------------------------
  Es una API REST en Flask que administra un catálogo de vehículos.

  - app.py: define la aplicación y los endpoints.
      GET    /salud            -> estado del servicio
      GET    /vehiculos        -> lista todos los vehículos
      POST   /vehiculos        -> crea un vehículo
      GET    /vehiculos/<id>   -> consulta un vehículo
      PUT    /vehiculos/<id>   -> actualiza un vehículo
      DELETE /vehiculos/<id>   -> elimina un vehículo

  - MongoDB guarda los vehículos (base de datos "automoviles", colección
    "vehiculos"). El nombre es único (sin distinguir mayúsculas).

  - Redis cachea las lecturas individuales. La primera consulta a
    GET /vehiculos/<id> lee de MongoDB y guarda en Redis; las siguientes
    (dentro del TTL) leen de Redis ("fuente": "redis").

  - cache_policy.py define el tiempo de expiración (TTL):
      * descripción con más de 20 caracteres -> no se cachea
      * nombre de hasta 5 caracteres         -> 15 segundos
      * nombre de hasta 10 caracteres        -> 20 segundos
      * nombre de más de 10 caracteres       -> 40 segundos

  - seed_data.py contiene 10 vehículos de ejemplo para cargar con el comando
    de seed.

2. DEPENDENCIAS
------------------------------------------------------------------------
  Servicios (vía Docker Compose):
    - MongoDB 8.0
    - Redis 7.4

  Librerías Python (requirements.txt):
    - Flask 3.1.0
    - pymongo 4.10.1
    - redis 5.2.1
    - python-dotenv 1.0.1
    - pytest 8.3.4
    - mongomock 4.3.0
    - fakeredis 2.26.2

  Requisito del sistema: Docker Desktop en ejecución.

3. COMANDOS PARA INICIALIZAR
------------------------------------------------------------------------
  cd "<RUTA DEL PROYECTO>"
  docker compose up --build -d
  docker compose exec api flask --app app seed

  La API queda disponible en: http://localhost:5000

  Ejecutar las pruebas:
  docker compose exec api pytest -q

  Detener los servicios:
  docker compose down
